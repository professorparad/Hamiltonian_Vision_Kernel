## 2. Standing rules from the PI (apply without being asked)

1. **Markup for every edit.** `\del{...}` = strikethrough (old text), `\add{...}` = bold black
   (new text). Macros are in the preamble (`ulem` + `\del`, `\add`). Put a space between
   `\del{..} \add{..}`. Headings and captions need a plain optional argument, e.g.
   `\subsection[Plain title]{\del{Old} \add{New}}`.
2. **Never modify results.** Only presentation and language. No new numbers, no recomputed
   statistics, no new analyses in the text. Anything like that goes into a red note for the
   student.
3. **Red notes for the student:** `{\color{red}\textbf{[Student: ...]}}`.
   **Plain red text without "[Student:" was written by the PI** and is for the student to
   rewrite. Never rewrite it yourself.
4. **Language:** simple Indian English (`-ise`, `colour`, `optimisation`), short sentences, one
   fact per sentence. No colon-then-loaded-clause, no em-dashes in prose, no AI filler words.
   Keep existing "rather than"; do not add new ones.
5. **Positive framing.** Headings and lead sentences say what the work does; limits come after,
   or go in the §5.4 limits list. The PI dislikes negative headings (e.g. the old
   "Why the physics-informed regulariser was inert").
6. **MPS stage is "quantum-inspired", never "classical".** Only the hardware it runs on is classical.
7. **Pace:** one small set of edits at a time, then stop for review.
8. **No large restructuring** (no results reordering, no new related-work section, no
   Introduction rewrite, no notation box or diagram). The PI declined these.
9. **Commit only when the PI asks.** The PI does the accept/reject pass at the very end.
10. Mechanics: `main_paper.tex` is LF; `sn-bibliography.bib` is CRLF. Bash heredocs break
    LaTeX backslashes — write Python edit scripts with the Write tool, assert each old string
    matches exactly once.

def body(t):
    t = t[t.index(r"\begin{document}"):]

def accepted(t):
    t = re.sub(r"\\del\{[^{}]*\}", "", t)
